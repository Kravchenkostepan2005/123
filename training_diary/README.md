# Дневник тренировок (Kivy, Python)

Минималистичное мобильное приложение для планирования недельных тренировок (5 базовых дней + до 2 дополнительных), фиксации подходов (повторы и вес в кг/фунтах), учёта веса тела, а также аналитики тоннажа по упражнениям и категориям.

## Возможности
- План недели: автоматически создаются 5 дней (Пн–Пт), можно добавить до 2 дополнительных дней (всего до 7)
- Ввод факта: для каждого подхода указывается план/факт повторений, вес и единица (kg/lb) с конвертацией
- Вес тела для каждой тренировки
- Категория тренировки (группа мышц) для сопоставимых сравнений
- Аналитика: график тоннажа по упражнению за выбранный период (неделя/месяц/3/6/12 мес), суммарный тоннаж по категориям
- SQLite-хранилище на устройстве

## Требования
- Python 3.10+
- Linux/macOS/Windows для разработки

## Установка зависимостей
```
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
pip install kivy_garden.matplotlib  # опционально для графиков
```

Если не установить `kivy_garden.matplotlib`, графики не будут отображаться, но приложение запустится.

## Запуск (десктоп)
```
python3 /workspace/training_diary/main.py
```

## Структура
- `main.py` — точка входа, экранный менеджер
- `screens/` — экраны: `planner.py`, `workout.py`, `analytics.py`
- `services/` — БД (`db.py`), репозиторий (`repository.py`), аналитика (`analytics.py`)
- `utils/` — утилиты: даты, конвертация единиц
- `training_diary.db` — файл SQLite (создаётся автоматически рядом с проектом)

## Сборка под Android (через Buildozer)
1. Установите buildozer и SDK/NDK зависимости (см. доку buildozer)
2. Создайте spec:
```
buildozer init
```
3. В `buildozer.spec` добавьте зависимости:
```
requirements = python3,kivy,kivymd,matplotlib,kivy_garden.matplotlib
```
4. Соберите:
```
buildozer -v android debug
```
APK появится в `bin/`.

Примечание: matplotlib тяжёлая, для продакшена можно заменить на лёгкую отрисовку (kivy canvas) или отключаемые графики.

## macOS (App)
